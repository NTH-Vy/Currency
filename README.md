# 💱 Currency Exchange - Full-stack Web Application

Ứng dụng web tra cứu và chuyển đổi tỷ giá tiền tệ theo thời gian thực. Dự án được phát triển hoàn chỉnh theo mô hình Full-stack, bao gồm Frontend, Backend và Database.

**🔗 Link Demo:** [https://nhvy.vercel.app/](https://nhvy.vercel.app/)

## 📖 Tổng quan

**Currency Exchange** là ứng dụng cho phép người dùng:

- Theo dõi tỷ giá hối đoái giữa các loại tiền tệ trên thế giới
- Chuyển đổi số tiền giữa các đơn vị tiền tệ khác nhau
- Quản lý tài khoản cá nhân (đăng ký, đăng nhập, cập nhật hồ sơ)
- Admin quản lý dữ liệu tỷ giá và người dùng

Dự án được thiết kế với giao diện thân thiện, responsive trên mọi thiết bị và tối ưu trải nghiệm người dùng.

---

## ✨ Tính năng nổi bật

### Người dùng (User)
- 🔐 Đăng ký / Đăng nhập tài khoản
- 👤 Quản lý hồ sơ cá nhân
- 💰 Xem tỷ giá theo thời gian thực
- 🔄 Chuyển đổi tiền tệ
- 📊 Xem biểu đồ biến động tỷ giá
- 📰 Xem tin tức tài chính 

### Quản trị viên (Admin)
- 📋 Quản lý danh sách người dùng
- 💱 Quản lý tỷ giá (thêm, sửa, xóa)
- 📈 Quản lý dữ liệu thống kê
- 📰 Quản lý tin tức tài chính
- 🔐 Bảo trì
